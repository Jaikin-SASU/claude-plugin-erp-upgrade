# Pricing plan and hosting constraints (verify live on https://www.odoo.com/pricing)

Checked 24 Sept 2026. Plans and their content change: always re-check and date your statement.

| Need | Consequence |
|---|---|
| External API access (integrations, BI, scripts, MCP) | "Access to data via the external API is only available on Custom Odoo pricing plans." — https://www.odoo.com/documentation/20.0/developer/reference/external_api.html |
| Studio customisation | Listed in the Custom plan column of the pricing page. |
| Custom modules (code) | Odoo.sh or on-premise; on Odoo Online, custom modules must be "Covered" (maintenance fee per 100 lines of code, agreement v13). |
| Employees without user account | Billable as Light Users under agreement v13 (24 Sept 2026). |
| Community edition | No Enterprise apps (e.g. Studio, accounting reports of Enterprise, Planning…), no official upgrade service — upgrades via OCA OpenUpgrade. |
| XML-RPC / JSON-RPC integrations | Deprecated; `db` service removed in 20; migrate to JSON-2. |

Prices (EUR, per user per month, yearly billing, checked 24 Sept 2026): Standard 24.90 € (19.90 € first year); Custom 44.90 € (35.90 € first year), up about 20 % from 37.40 € on 23 Sept 2026. First-year discounts are not the recurring price.
